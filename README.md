# Movie App 🎬

A dynamic web application that allows users to explore movies, view details, and manage their favorite list. This project was built to practice fetching real-world data from APIs and handling asynchronous operations in JavaScript.

## 🚀 Live Demo
[View Project Live](https://hamadashehta.github.io/movie-app/)

## ✨ Features
- **Real-time Search:** Find any movie instantly using the search bar.
- **Movie Details:** View summaries, ratings, and release dates.
- **Favorites System:** Add your favorite movies to a dedicated list and remove them whenever you want.
- **Fully Responsive:** Optimized for all screen sizes (Mobile, Tablet, and Desktop) using Bootstrap.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Framework:** Bootstrap 5
- **API:** [TMDB API](https://www.themoviedb.org/)
